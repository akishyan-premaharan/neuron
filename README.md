This project made for learning purposes (Machine Learning & Artifical Intelligence), is a simulation of a neuron that:

- 🎯  Attempts to predict the target value (The number 2)

- 🔽  Has 5 inputs/weights

- 📉  Uses **the Mean Absolute Error** as the loss function because the data is continuous 

- 🏗️  Is built on **OOP** classes to help code the behaviour of an actual neuron (Activation, Learning from mistakes)

- 📊  Is powered by the PyTorch machine learning library, via the **tensor, sigmoid() and abs()** algorithms in the code

## How to use this Project?

To use my project, you can:

- Run it on a Python environment, such as **VSCode/PyCharm/OneCompiler**

**NOTE:** You should run this code on a cloud hosted IDE if you want multiple epoches, that's what I did
